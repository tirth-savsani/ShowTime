# ShowTime

ShowTime is a BookMyShow-style movie ticket booking web application built with the MERN stack. It features a backend-heavy MVC architecture with a service layer, atomic seat holds, Razorpay payment verification, and a responsive frontend replicating the BookMyShow user experience.

## Tech Stack
- **Backend:** Node.js (ES modules), Express, MongoDB Atlas with Mongoose, JWT in httpOnly cookie, Zod, Razorpay (test mode), Multer + Cloudinary, node-cron, helmet, cors, express-rate-limit, Jest + Supertest.
- **Frontend:** React + Vite, Redux Toolkit, React Router, Tailwind CSS, react-hot-toast.

## Project Structure
- `backend/` - Express REST API (MVC + Service layer)
- `frontend/vite-project/` - React frontend
- `docs/` - Specifications and configuration guides
